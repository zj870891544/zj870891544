## Krillion Today

[Krillion Today](https://krilliontoday.com/) is an independent companion for the Krillion trivia game, with daily answers, spoiler-free hints, an answer archive, and guides to the rules and scoring.

[Play the original Unlimited practice game](https://krilliontoday.com/unlimited): seven prompts per round, 25 seconds per prompt, topic categories, and shareable friend challenges. Practice is free, needs no account, and has no daily limit.

- [Today's hints](https://krilliontoday.com/hints)
- [Past answer archive](https://krilliontoday.com/archive)
- Contact: [hello@krilliontoday.com](mailto:hello@krilliontoday.com)

Krillion Today is an independent fan-made site, not affiliated with or endorsed by the original Krillion game. Practice questions and scoring are original.
